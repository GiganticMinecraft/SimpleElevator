# SimpleElevator 詳細設計

基本方針と外部インターフェースは [基本設計](BASIC_DESIGN.md) を参照する。

## 1. エレベーター台の判定

エレベーター台は、次の 2 ブロックの組み合わせで表す。

```text
プレイヤーの足元
┌────────────────────────┐
│ 固定されたプレート Material │  y
├────────────────────────┤
│ 固定された土台 Material     │  y - 1
└────────────────────────┘
```

現在位置または移動先の台は、次の条件をすべて満たす必要がある。

- プレイヤーの現在位置のブロック、または検索対象ブロックが `HEAVY_WEIGHTED_PRESSURE_PLATE` である
- その直下のブロックが `IRON_BLOCK` である
- 判定対象は位置のブロック座標 (`getBlockX()` / `getBlockY()` / `getBlockZ()`) である

移動先の検索は現在の台を基準に、同じワールドの同じ X/Z 座標で行う。水平方向の移動は発生しない。

## 2. 移動開始条件

イベントがキャンセル済みの場合は、上移動・下移動とも処理しない。イベントリスナーは通常優先度で登録される。

### 2.1 上移動

`PlayerMoveEvent` で、次の条件をすべて満たすと上移動を試みる。

1. プレイヤーが飛行中ではない
2. 移動後の Y 座標が移動前より高い
3. プレイヤーが `elevator.up` 権限を持つ
4. 移動後の現在位置がエレベーター台上である
5. 上方向 1 ブロック以上、ワールドの高度範囲内に有効な移動先がある

飛行中、Y 座標が変化しない移動や下降する移動、権限のない移動では
上移動を試みない。上方向の処理には `PlayerMoveEvent` の移動先 (`to`) の
位置を使用する。

### 2.2 下移動

`PlayerToggleSneakEvent` で、次の条件をすべて満たすと下移動を試みる。

1. しゃがみ状態になるイベントである (`isSneaking() == true`)
2. プレイヤーが `elevator.down` 権限を持つ
3. プレイヤーの現在位置がエレベーター台上である
4. 下方向 1 ブロック以上、ワールドの高度範囲内に有効な移動先がある

しゃがみ解除イベント (`isSneaking() == false`) では処理しない。下方向の処理にはイベント処理時点のプレイヤー位置を使用する。

## 3. 移動先の検索と安全判定

現在のエレベーター台から、指定方向に 1 ブロックずつ、近い順に検索する。上方向は`World#getMaxHeight()`未満、下方向は`World#getMinHeight()`より上の範囲まで検索する。

各候補は次の順に判定する。

1. 候補ブロックがエレベーター台である
2. 候補台の直上のブロックが移動可能な空間である

最初に両方を満たした候補を移動先にする。近い候補の直上が不適切な場合は、その候補を飛ばして次の候補を検索する。候補が見つからない場合は移動しない。

移動先の直上のブロックは、`Block#isPassable()` が `true` で、かつ次の危険・不適切な Material ではない必要がある。

- `WATER`
- `LAVA`
- `COBWEB`
- `SWEET_BERRY_BUSH`
- `Tag.FIRE` に含まれる火（通常の火、ソウルファイアなど）

したがって、固体ブロック、液体、火、クモの巣、スイートベリーの茂みが候補台の直上にある場合、その台は移動先にならない。

## 4. テレポートの挙動

移動が成立した場合、現在位置を複製して Y 座標だけを移動先プレートのブロック Y 座標に変更し、その位置へテレポートする。

- X 座標を維持する
- Z 座標を維持する
- Yaw（向き）を維持する
- Pitch（視点の上下角）を維持する
- ワールドを変更しない

テレポートが成功すると、移動先で `ENTITY_ENDER_DRAGON_FLAP` を音量 `1.0`、ピッチ `1.0` で再生する。

テレポート API が失敗した場合は移動を成立させず、音も再生しない。

## 5. 固定値

エレベーター台の Material は次の値に固定する。

- プレート: `HEAVY_WEIGHTED_PRESSURE_PLATE`
- 土台: `IRON_BLOCK`

## 6. 権限の詳細

権限は `plugin.yml` に宣言され、イベント処理時に個別に確認する。上移動の権限と下移動の権限は独立している。

## 7. プラグインのライフサイクル

### 7.1 有効化時

1. `ElevatorMovementService` を生成する
2. `PlayerMoveEvent` と `PlayerToggleSneakEvent` のリスナーを登録する

### 7.2 無効化時

特別な終了処理は行わない。

## 8. 構成要素

| 要素 | 役割 |
| --- | --- |
| `SimpleElevator` | プラグインの起動とリスナーの登録 |
| `ElevatorListener` | 上下移動を開始するイベントと権限の判定 |
| `ElevatorMovementService` | 固定台の検出、移動先検索、安全判定、テレポート、音 |

## 9. 検証対象

テストでは、少なくとも次の挙動を確認する。

- 固定された Material による台の判定
- 上移動の権限、Y 座標上昇、飛行中の抑止、キャンセルイベントの扱い
- 下移動の権限、しゃがみ開始時のみの処理
- 最寄りの有効な台の選択と、無効な台のスキップ
- ワールドの高度範囲内にある遠距離の台の検索
- 移動先が未存在の場合の不移動
- 移動成功後の座標・視点維持と効果音
- 移動直後の再移動
