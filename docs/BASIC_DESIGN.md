# SimpleElevator 基本設計

## 1. 目的と対象範囲

SimpleElevator は、同じワールド内の同じ X/Z 座標に設置されたエレベーター台の間で、プレイヤーを上下方向に移動させる Paper プラグインである。

詳細な判定順序や実装規則は [詳細設計](DETAIL_DESIGN.md) を参照する。

## 2. 動作環境とプラグイン情報

- 対象 API: Paper API `1.18.2-R0.1-SNAPSHOT`
- Java: 17
- `plugin.yml` の API バージョン: `1.18`
- プラグイン名: `SimpleElevator`
- メインクラス: `click.seichi.simpleelevator.SimpleElevator`
- プラグインバージョン: Gradle のプロジェクトバージョンを `plugin.yml` に展開する

プラグイン JAR には Paper API を同梱せず、実行先の Paper サーバーが提供する API を使用する。

## 3. 基本機能

| 機能 | 概要 |
| --- | --- |
| エレベーター台 | `HEAVY_WEIGHTED_PRESSURE_PLATE` と、その直下の `IRON_BLOCK` の組み合わせで判定する |
| 上移動 | プレイヤーの Y 座標が上昇したとき（飛行中を除く）、上方向の最寄りの有効な台へ移動する |
| 下移動 | しゃがみ開始時、下方向の最寄りの有効な台へ移動する |
| 移動範囲 | 同じワールドの同じ X/Z 座標を、ワールドの高度範囲内で検索する |
| 移動先判定 | 台の存在と、台の直上にプレイヤーが入れる安全な空間があることを確認する |

移動時はプレイヤーの X 座標、Z 座標、Yaw、Pitch を維持し、Y 座標だけを移動先台の位置へ変更する。移動成功時には効果音を再生する。

## 4. 外部インターフェース

### 4.1 固定値

エレベーター台は、`HEAVY_WEIGHTED_PRESSURE_PLATE` と、その直下の `IRON_BLOCK` の組み合わせで判定する。

### 4.2 権限

| 権限ノード | 既定値 | 基本的な意味 |
| --- | --- | --- |
| `elevator.up` | `true` | 上方向の移動を許可する |
| `elevator.down` | `true` | 下方向の移動を許可する |

上移動と下移動の権限は独立している。

## 5. 移動の概要

### 5.1 上移動

プレイヤーがエレベーター台上で飛行していない状態で上方向へ移動し、`elevator.up` 権限を持っている場合、上方向の最寄りの有効な台へ移動する。

### 5.2 下移動

プレイヤーがエレベーター台上でしゃがみ始め、`elevator.down` 権限を持っている場合、下方向の最寄りの有効な台へ移動する。

### 5.3 移動先

移動先は現在の台と同じワールドの同じ X/Z 座標に限定する。候補台の直上が固体・危険なブロックなどで塞がっている場合、その台は使用しない。
